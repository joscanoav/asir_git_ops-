La Chuleta del SysAdmin

Comando Icono La Metáfora Cuándo usarlo
git init 📦 Comprar una caja nueva Al empezar un proyecto nuevo.
git clone <url> 🐑 Clonar el almacén Al bajar un proyecto existente.
git status 👀 Mirar qué hay en la mesa Siempre. Antes de hacer nada.
git add . 📥 Meter archivos en la caja Cuando terminas de editar un archivo.
git commit -m "" 🏷️ Precintar y etiquetar la caja Para guardar una "foto" del trabajo.
git push 🚚 Enviar camión a la nube Para subir cambios a GitHub.
